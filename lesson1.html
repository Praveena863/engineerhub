Developer note — swapping in a realistic human AI avatar

The character above is a lightweight illustrated avatar driven entirely by your browser's built-in speechSynthesis — no signup, no API key, works offline. If you later want a realistic human presenter (HeyGen, Synthesia, D-ID, Colossyan, etc.), replace the <svg> stage with a <video> element and generate the clip through that provider's API using the same lesson script already defined in LESSON.sections below. A minimal HeyGen-style integration looks like this (run this on your own server — never expose your API key in client-side code):

// server-side (e.g. Node/Express) — keep the API key here, never in the browser
app.post('/api/generate-avatar-video', async (req, res) => {
  const { script, avatarId, voiceId } = req.body;
  const response = await fetch('https://api.heygen.com/v2/video/generate', {
    method: 'POST',
    headers: {
      'X-Api-Key': process.env.HEYGEN_API_KEY,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      video_inputs: [{
        character: { type: 'avatar', avatar_id: avatarId },
        voice: { type: 'text', input_text: script, voice_id: voiceId }
      }]
    })
  });
  const data = await response.json();
  res.json(data); // returns a video_id you poll until status = 'completed'
});

// front-end — once the render is done, just swap the SVG stage for:
// <video id="instructorVideo" src="RETURNED_VIDEO_URL" controls></video>
